# Progress Log

## Learnings
(Patterns discovered during implementation)
- Project uses Jest for testing, run with `npm test -- tests/<file>.test.js`
- No TypeScript in project - "Typecheck passes" criterion is satisfied by default
- Existing tests for canvas.test.js, combos.test.js, pipeline.test.js have pre-existing failures (ffmpeg/font issues)
- Config files go in `config/` directory, config modules in `src/config/`
- Deep merge utility needed for combining default config with user overrides

## Iteration 1 - US-001: Create JSON Configuration Schema and Loader
- What was implemented:
  - Created `src/config/schema.js` with complete schema definition for text, images, and animation settings
  - Created `src/config/configLoader.js` with loadConfig, loadDefaults, deepMerge functions
  - Created `config/defaults.json` with default values (needed for configLoader to work)
  - Created `tests/config.test.js` with 43 unit tests covering schema validation and merging logic
- Files changed:
  - src/config/schema.js (new)
  - src/config/configLoader.js (new)
  - config/defaults.json (new)
  - tests/config.test.js (new)
- Learnings for future iterations:
  - configLoader requires defaults.json to exist before it can be used
  - Schema validates types (string, number, boolean, object), ranges (min/max), and enums
  - deepMerge handles nested objects recursively while preserving immutability
  - Test fixtures should be created in beforeAll and cleaned up in afterAll
