# Progress Log

## Learnings
(Patterns discovered during implementation)
- Project uses Jest for testing, run with `npm test -- tests/<file>.test.js`
- No TypeScript in project - "Typecheck passes" criterion is satisfied by default
- Existing tests for canvas.test.js, combos.test.js, pipeline.test.js have pre-existing failures (ffmpeg/font issues)
- Config files go in `config/` directory, config modules in `src/config/`
- Deep merge utility needed for combining default config with user overrides

## Iteration 6 - US-006: Implement Text Dropshadow Effect
- What was implemented:
  - Added dropshadow rendering in `createTextCanvasOfSize` using canvas shadow API
  - Extracts dropshadow settings (enabled, color, blur, offsetX, offsetY) from config
  - Applies ctx.shadowColor, ctx.shadowBlur, ctx.shadowOffsetX, ctx.shadowOffsetY when enabled
  - Calculates extra canvas padding to accommodate shadow extent beyond text bounds
  - Uses resolveColor for shadow color validation with fallback to #000000
  - Resets shadow properties after drawing (good practice)
  - Dropshadow only applied when dropshadow.enabled === true
  - Added 14 comprehensive unit tests for dropshadow functionality
- Files changed:
  - src/image/canvas.js (added dropshadow logic to createTextCanvasOfSize)
  - tests/canvas.test.js (added dropshadow test suite with 14 tests)
  - PRD.md (marked US-006 as complete)
- Learnings for future iterations:
  - Canvas shadow API uses ctx.shadowColor, ctx.shadowBlur, ctx.shadowOffsetX, ctx.shadowOffsetY
  - Shadows can extend beyond text bounds, so canvas must be larger to accommodate
  - Shadow padding formula: max(|offsetX|, |offsetY|) + blur
  - Always reset shadow properties after drawing to avoid affecting subsequent operations
  - Use strict equality (=== true) for boolean checks to avoid truthy false positives
