## Iteration 71 - US-071: Implement Duration Bar Move (Middle Drag)
- What was implemented:
  - Added 'move' drag type handling in `onDurationBarDrag()` function
  - Calculates duration (initialEndFrame - initialStartFrame) and preserves it during drag
  - Calculates frame delta by converting initial and current mouse positions to frames
  - New positions: newStartFrame = initialStartFrame + frameDelta, newEndFrame = initialEndFrame + frameDelta
  - Clamping at left edge: if newStartFrame < 0, set newStartFrame=0 and newEndFrame=duration
  - Clamping at right edge: if newEndFrame > maxFrame, set newEndFrame=maxFrame and newStartFrame=maxFrame-duration
  - Updates both overlay object and legacy state when dragging
  - Duration bar visually updates in real-time via existing `updateOverlayDurationBar()` call
  - Both Start/End Frame inputs update via existing `updatePropertiesPanel()` call
  - Cursor changes to 'grabbing' already handled in `onDurationBarDragStart()` (line 4356)
  - 512 tests pass (1 pre-existing canvas native binding failure is environment issue)
- Files changed:
  - editor/index.html (added else if branch for 'move' drag type in onDurationBarDrag)
  - PRD.md (marked US-071 as complete)
  - progress.txt (added iteration notes)
- Learnings for future iterations:
  - Move drag preserves duration by applying same delta to both start and end frames
  - Use initialStartFrame and initialEndFrame (from drag start) for calculations, not current overlay values
  - Clamping must adjust both frames when hitting boundaries to preserve duration
  - When hitting left boundary: set start=0, end=duration; when hitting right: set end=max, start=max-duration
